# 여행 플래너 (Gemini + Kakao API 기반)

날짜만 입력하면 Gemini AI가 당일 여행 일정을 추천해주고, Kakao 지도 API로 추천 지역의 맛집을 검색해서 Markdown 리포트로 정리해주는 파이썬 프로그램입니다.

## 프로그램 개요

1. 사용자가 날짜를 입력하면 Gemini API에 요청을 보내 여행지, 시간대별 일정, 맛집 검색 키워드를 JSON 형태로 추천받습니다.
2. Gemini 호출/파싱이 실패하면(재시도 포함) 서울 기본 일정으로 대체됩니다.
3. 추천받은 맛집 키워드로 Kakao Local API를 호출해 실제 맛집 정보(이름, 주소, 전화번호, 링크 등)를 검색합니다.
4. 위 결과를 종합해 Markdown 리포트를 생성하고, JSON 원본과 함께 `results/` 폴더에 저장합니다. 실행 중 발생한 오류는 모두 리포트의 "오류 요약" 섹션에 함께 기록됩니다.

## 사전 준비물

- Python 3.9 이상
- 필요한 패키지 설치

```bash
pip install requests python-dotenv
```

- Google Gemini API 키 ([Google AI Studio](https://aistudio.google.com/)에서 발급)
- Kakao REST API 키 ([Kakao Developers](https://developers.kakao.com/)에서 발급, 애플리케이션 등록 후 "카카오 로컬" 사용 설정 필요)

## API 키 설정 방법

1. 프로그램 파일(`여행_플래너.py`)과 같은 폴더에 `.env` 파일을 생성합니다.
2. 아래 내용을 채워 넣습니다.

```env
GEMINI_API_KEY=발급받은_Gemini_API_키
GEMINI_MODEL=gemini-3.6-flash
KAKAO_REST_API_KEY=발급받은_Kakao_REST_API_키
```

- `GEMINI_MODEL`은 생략 가능하며, 생략 시 기본값(`gemini-3.6-flash`)이 사용됩니다.
- `.env` 파일은 프로그램이 `load_dotenv()`로 자동으로 읽어들입니다.

## 실행 방법

터미널에서 아래와 같이 날짜(`-date`)를 지정해 실행합니다.

```bash
python 여행_플래너.py -date 2026-08-20
```

실행하면 콘솔에 진행 상황(`[LOG]`, `[DEBUG]`, `[ERROR]`)이 출력되며, 다음 순서로 동작합니다.

1. GEMINI_API_KEY 설정 여부 확인 (없으면 즉시 종료)
2. Gemini로 여행 일정 추천 생성
3. 추천받은 키워드로 Kakao 맛집 검색
4. Markdown 리포트 생성
5. 결과 파일 저장

## 오류 처리 정책

프로그램은 오류 상황에 따라 아래처럼 다르게 동작합니다.

| 상황 | 동작 |
| --- | --- |
| `GEMINI_API_KEY` 미설정 | 다른 로직을 실행하지 않고 즉시 종료(`exit code 1`)하며, 콘솔에 `.env` 설정 방법을 안내합니다. |
| Kakao 맛집 검색 API 실패 (네트워크 오류, 인증 오류, 쿼터 초과 등) | 프로그램은 중단되지 않고 계속 진행되며, 리포트의 맛집 섹션이 "데이터 없음"으로 표시됩니다. |
| Gemini 응답의 JSON 파싱 실패 | 필수 키만 다시 출력하도록 프롬프트를 수정해 1회 재시도합니다. 재시도까지 실패하면 서울 기본 일정(fallback)으로 대체됩니다. |

- 실행 중 발생한 모든 오류는 내부적으로 오류 목록(`errors`)에 `{단계, 메시지}` 형태로 누적되며, 오류가 없으면 빈 목록으로 유지됩니다.
- 이 목록은 결과 JSON의 `errors` 키와 Markdown 리포트의 "## 오류 요약" 섹션에 그대로 반영됩니다(오류가 없으면 "오류 없음"으로 표시).

## 결과물 확인 방법

실행이 끝나면 프로그램 폴더 아래 `results/` 폴더가 생성되고, 다음 두 파일이 저장됩니다.

- `results/{날짜}_raw.json` : Gemini 추천 결과, 맛집 검색 결과, 오류 목록(`errors`)이 담긴 원본 JSON
- `results/{날짜}_report.md` : 사람이 읽기 편한 형태로 정리된 최종 Markdown 리포트 (마지막에 "오류 요약" 섹션 포함)

예를 들어 `-date 2026-08-20`으로 실행하면 `results/2026-08-20_report.md` 파일을 열어 여행지, 시간대별 일정, 맛집 리스트, 그리고 실행 중 오류가 있었는지를 한 번에 확인할 수 있습니다.

## ⚠️ API 키 유출 방지 주의 사항

- **`.env` 파일을 절대 Git 저장소에 커밋하지 마세요.** 프로젝트에 `.gitignore` 파일을 만들고 아래 줄을 추가하세요.

  ```
  .env
  ```

- **API 키를 코드에 직접 하드코딩하지 마세요.** 항상 `.env` 파일과 `os.getenv()`를 통해서만 불러오세요.
- **콘솔 로그나 캡처 화면을 공유할 때 주의하세요.** 이 프로그램은 디버깅을 위해 API 응답 본문 일부를 출력(`[DEBUG] Gemini body`, `[DEBUG] Kakao body`)하는데, 응답 내용 자체에는 보통 키가 노출되지 않지만 화면을 공유하거나 로그를 외부에 올릴 때는 혹시 모를 민감 정보가 없는지 확인하세요.
- **`results/` 폴더 안의 JSON/Markdown 파일에는 API 키가 포함되지 않지만**, 공개 저장소에 올리기 전에는 개인정보(맛집 전화번호, 주소 등)가 민감하지 않은지 한 번 더 확인하세요.
- **키가 노출되었다고 의심되면 즉시 재발급하세요.** Google AI Studio와 Kakao Developers 콘솔에서 기존 키를 폐기(재발급)할 수 있습니다.
- 여러 명이 함께 개발한다면 각자 로컬에 개별 `.env` 파일을 두고, 팀 내 공유가 필요하면 1Password, Bitwarden 등 안전한 비밀번호 관리 도구를 이용하세요.
